# 解像度の実験室

画像の解像度を下げて、もう一度上げても元に戻らないことを確かめる、高校生向けの教材です。

- **STEP 1 解像度を下げる**：画像の大きさはそのままで、中身の画素数を減らします（解像度 % / 横のドット数 / ドットの大きさで指定）。
- **STEP 2 解像度を上げる**：STEP 1 で下げた画像の解像度を、同じ方法で上げます。「元と同じ色の画素」の割合や「元との違い」の表示で、失われた細部が戻らないことが分かります。

`index.html` をブラウザで開くだけで使えます（GitHub Pages でも公開できます）。画像はブラウザの中だけで処理され、どこにも送信されません。
